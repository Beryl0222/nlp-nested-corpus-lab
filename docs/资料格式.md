# 数据约定

documents为原文与来源族；opinions为标注员提议，state=proposed并不代表裁定。segments是左闭右开码点区间，surface仅作人工检查。关系端点在同份意见内引用实体id。ontologies说明类型含义与关系允许端点，类型改名没有默认业务迁移。revisions是可由使用者提交的演练动作。

全部人物、产品、组织和业务记录均为本地合成资料。原文使用UTF-8，文本区间按原文Unicode码点左闭右开计数；不同修订的区间不互换。ID只用于引用，不携带判定结果。data中的学习标记是已有人工例子，可用以训练，业务记录的处理结果仍需由产品产生。

嵌套与不连续以segments表示，按原文从左到右排列，不能重叠自身。跨提及关系在每份意见内引用。未知新类型与未决意见可保留供人工查看，不可作为已裁定的新类型训练标记。学习样例是意见输入，并非全部已仲裁。
